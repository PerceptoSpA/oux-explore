# Oux Explore - Sitio Web Corporativo

## 1. Descripción del Proyecto
Sitio web corporativo para Oux Explore, empresa especializada en servicios de minería: campañas de sondaje, escaneo de muestras mineras, geología y geofísica. El sitio presenta la empresa, sus servicios, equipo de profesionales y datos de contacto, con un diseño elegante y profesional inspirado en el sector minero-industrial.

**Público objetivo:** Empresas mineras, inversionistas del sector, profesionales de geología y minería.

## 2. Estructura de Páginas
- `/` - Inicio (Hero + Servicios + Sobre Nosotros + Equipo + Contacto — una sola página con secciones)

## 3. Funcionalidades Principales
- [ ] Hero section con imagen de fondo impactante del sector minero
- [ ] Sección de servicios (Sondaje, Escaneo de Muestras, Geología, Geofísica)
- [ ] Sección Sobre Nosotros con descripción de la empresa
- [ ] Sección de Equipo profesional
- [ ] Sección de Contacto con formulario funcional
- [ ] Footer con datos de contacto, enlaces y redes sociales
- [ ] Navbar con scroll suave a secciones
- [ ] Diseño responsive (desktop-first)

## 4. Modelo de Datos
No se requiere base de datos. El formulario de contacto usará el sistema de formularios integrado de Readdy.

## 5. Integraciones Backend / Terceros
- Formulario Readdy: Para el formulario de contacto
- Sin necesidad de Supabase, Shopify ni Stripe por ahora
